
# store_tools

`store_tools` is a small Python GUI application designed to assist with the management of a small business.

![main screen](https://github.com/user-attachments/assets/fdfecec2-7de7-4389-aa32-0557ae06e371)

## Features

This application provides the following functionalities:

* **Currency Conversion:** Convert local currency to US dollars and vice versa.
* **Product Profit Calculation:** Calculate the profit margin for products.
* **Product Price Calculation by Weight:** Determine a product's selling price based on its weight.
* **Dollar Value Storage:** Manage and store the current dollar exchange rate.
* **Exchange rate from Internet:** Receive the exchange from Internet.
* **Seach by Date:** Seach exchange rate by date.
